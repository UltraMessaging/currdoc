Release Notes
UM Version 6.17.2

The most significant updates to UM version 6.17.2 are further hardening of the DRO Hotlinks feature (including smart-source support and several stability fixes surfaced during customer testing of the 6.17.0.5 EBF) and security-scan remediation in the Stateful Resolver Service (SRS) and the Persistent Store (umestored).

For general upgrade instructions, see Upgrade Procedure.

Also see Deprecations.


Enhancements for 6.17.2  <-


Streaming Enhancements for 6.17.2  <-

The following new features and enhancements apply to UMS, UMP, and UMQ products.

  • Smart Source Support for Hotlinks. The DRO Hotlinks feature now supports Smart Sources. Note that multi-threaded access to smart-source sending is still not supported; smart sources remain single-threaded.

Fixed Problems and Limitations for 6.17.2  <-


Streaming Fixed Problems and Limitations for 6.17.2  <-

The following bug fixes apply to UMS, UMP, and UMQ products.

Change Request

Description

11621

FIXED: Topic-manager crash on the receiver event-queue dispatch thread under the DRO Hotlinks feature. The crash was traced to unsafe reuse of the same clientd pointer as both the OTID entry and source_clientd when accessed from the event-queue thread.

11622

FIXED: Fatal assertion [stream!=NULL] at lbmqr.c:965 in the UIM query-response send path. The assertion could fire under sustained response traffic even when a matching stream did exist for the destination.

11623

FIXED: lbm_event_queue_from_rcv() returned NULL when called against a receiver configured with use_hotlink. The function now returns the receiver's associated event queue, matching the non-hotlinked behavior. Applications that saved the event queue at receiver-create time as a workaround can drop that pattern.

11625

FIXED: Hotlink-promoted receivers (those configured with use_hotlink) could execute deferred channel-cleanup callbacks against a receiver whose state had already been torn down, resulting in use-after signatures and crashes during shutdown or spectrum reconfiguration.

11633

FIXED: Security-scan vulnerabilities in the Stateful Resolver Service (SRS) java packages and in third-party libraries used by umestored. Vulnerable jar files were upgraded and related source-side changes were merged.

11637

FIXED: Silent message loss for wildcard receivers subscribing via lbm_wildcard_rcv_subscribe_channel when the matching source was discovered after the subscribe call, the per-topic receiver was HF-wrapped (use_hotlink = 1), and the rcv-attr had unrecognized_channel_behavior = discard. Wildcard receivers now deliver these messages correctly.
